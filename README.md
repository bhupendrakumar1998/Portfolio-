# Bhupendra Kumar Ahirwar - Portfolio

A responsive static portfolio built with HTML, CSS and JavaScript.

## Files
- index.html
- style.css
- script.js

## Before publishing
1. Replace the placeholder email and phone in `index.html`.
2. Add your GitHub and LinkedIn links if needed.
3. Replace the Formspree placeholder in the contact form with your real Formspree form endpoint, or remove the form if you don't need it.
4. Add your resume file and a download button if desired.

## Netlify
You can deploy this project by logging into Netlify and dragging the `bhupendra-portfolio` folder into the deploy area, or by connecting a GitHub repository.
